These builds are unsigned. Windows and macOS will warn you the first time you open the app. The steps under each download show how to get past the warning. Check the file against the published checksums if you want to be sure it is the file built from this repository.

Downloads

Windows

Download for Windows Windows 10 or 11, 64-bit. Installer (.exe), for your user only, no admin prompt.
  1. Open the downloaded file.
  2. If you see Windows protected your PC, click More info, then Run anyway.
  3. Open Sparkbot Roundtable from the Start menu.

macOS

Download for Apple silicon Download for Intel Macs macOS 11 or later. Not sure which Mac you have? Apple menu, About This Mac: "Apple M…" is Apple silicon.
  1. Open the .dmg and drag the app to Applications.
  2. Open it once. macOS will refuse because the app is unsigned.
  3. Go to System Settings, Privacy & Security, scroll down and click Open Anyway.
Or paste this in Terminal after step 1: 
xattr -dr com.apple.quarantine "/Applications/Sparkbot Roundtable.app"

Linux

Download AppImage Download .deb (Debian, Ubuntu) 64-bit x86. Built on Ubuntu 22.04.
  1. AppImage: make it runnable, then open it.
chmod +x Sparkbot-Roundtable-v0.0.01-linux-x64.AppImage
./Sparkbot-Roundtable-v0.0.01-linux-x64.AppImage
  1. .deb: install it with apt.
sudo apt install ./Sparkbot-Roundtable-v0.0.01-linux-x64.deb

Before you start

  • It runs on your computer only. The app starts its own local service on 127.0.0.1 and needs no account. Rooms and messages stay on your machine.
  • Bring your own agents. To seat an agent you need Claude Code or Codex installed and signed in on the same computer. The app shows the two commands to paste for each seat. Sparkbot itself makes no model calls and asks for no API keys.
  • No automatic updates. To update, download a newer version here and install it over the old one.
  • One computer per room. Guests joining from other devices are not supported in this version.
  • How far it has been tested. The Windows installer has been through a hands-on pilot. The macOS and Linux packages are new in this version and have only had automated build checks. Please report what breaks.
